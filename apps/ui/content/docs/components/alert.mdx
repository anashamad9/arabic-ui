## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/alert.tsx`. مسار الاستيراد: `@coss/ui/components/alert`.

## الاستخدام

```tsx
import { Alert, AlertDescription, AlertTitle } from "@coss/ui/components/alert"
```

```tsx
<Alert>
  <AlertTitle>تنبيه!</AlertTitle>
  <AlertDescription>
    يمكنك إضافة مكونات وتبعيات إلى التطبيق الخاص بك باستخدام سطر الأوامر.
  </AlertDescription>
</Alert>
```

## مرجع الواجهة البرمجية

مكوّن مخصّص للمكتبة.

### التنبيه

حاوية الجذر للتنبيه.

| الخاصية      | النوع                                                        | الافتراضي     | الوصف                                      |
| --------- | ----------------------------------------------------------- | ----------- | ------------------------------------------------ |
| `variant` | `"default" \| "error" \| "info" \| "success" \| "warning"` | `"default"` | يتحكم في تصميم التنبيه ونظام الألوان      |

### AlertTitle

نص العنوان للتنبيه. يجعل كما على غرار `div`.

### AlertDescription

وصف النص للتنبيه. يجعل على غرار `div` مع لون المقدمة صامت.

### AlertAction

حاوية لأزرار العمل. المواضع تلقائيا إلى اليمين على شاشات أكبر.
