## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/separator.tsx`. مسار الاستيراد: `@coss/ui/components/separator`.

## الاستخدام

```tsx
import { Separator } from "@coss/ui/components/separator"
```

```tsx
<Separator />
```
