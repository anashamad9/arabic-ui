## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/pagination.tsx`. مسار الاستيراد: `@coss/ui/components/pagination`.

## الاستخدام

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@coss/ui/components/pagination"
```

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## مرجع الواجهة البرمجية

مكوّن مخصّص للمكتبة.

### ترقيم الصفحات

حاوية الملاحة الجذر مع `role="navigation"` و `aria-label="pagination"`.

### PaginationContent

حاوية قائمة غير مرتبة لعناصر ترقيم الصفحات.

### PaginationItem

قائمة فردية حاوية البند.

### PaginationLink

عنصر الارتباط لأرقام الصفحات. يدعم `render` الخاصية.

| الخاصية       | النوع                                  | الافتراضي     | الوصف                                      |
| ---------- | ------------------------------------- | ----------- | ------------------------------------------------ |
| `isActive` | `boolean`                             | -           | يسلط الضوء على الرابط باعتباره الصفحة الحالية          |
| `size`     | `"default" \| "icon"`                 | `"icon"`    | التحكم في حجم الرابط                           |
| `render`   | `React.ReactElement`                  | -           | تقديم كعنصر مختلف (على سبيل المثال، نكست Link) |

### PaginationPrevious

رابط إلى الصفحة السابقة. يتضمن رمز شيفرون الأيسر والنص "السابق".

### PaginationNext

رابط إلى الصفحة التالية. يتضمن نص "التالي" وأيقونة شيفرون اليمنى.

### PaginationEllipsis

مؤشر القطع الناقص للصفحات التي تم تخطيها. يعرض "..." مع نص قارئ الشاشة "المزيد من الصفحات".
