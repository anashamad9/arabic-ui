## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/slider.tsx`. مسار الاستيراد: `@coss/ui/components/slider`.

## الاستخدام

```tsx
import { Slider, SliderValue } from "@coss/ui/components/slider"
```

```tsx
<Slider />
```

## مرجع الواجهة البرمجية

### شريط التمرير

المكوّن الأساسي. غلاف منسّق للمكوّن `Slider.Root` من واجهة المستخدم الأساسية مع قيم الحد الأدنى / الحد الأقصى الافتراضية والإبهام محاذاة الحافة.

| الخاصية  | النوع     | الافتراضي | الوصف                                      |
| ----- | -------- | ------- | ------------------------------------------------ |
| `min` | `number` | `0`     | الحد الأدنى لقيمة شريط التمرير                      |
| `max` | `number` | `100`   | الحد الأقصى لقيمة المنزلق                      |

ملاحظة: مجموعات المكونات `thumbAlignment="edge"` بشكل افتراضي ، والذي محاذاة الإبهام إلى حافة المسار بدلاً من توسيطها.

### SliderValue

يعرض القيمة الحالية. غلاف نمط ل `Slider.Value` من مكتبة بيس.

## الأمثلة

للتسميات والتحقق مع دعم سهولة الوصول، يُفضّل استخدام `Field` مكون لتغليف مربعات الاختيار. انظر المثال ذي الصلة: [حقل شريط التمرير](/ui/docs/components/field#حقل-شريط-التمرير).
