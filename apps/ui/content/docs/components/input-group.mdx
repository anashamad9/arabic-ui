## مرجع الواجهة البرمجية

### InputGroup

المكون الرئيسي الذي يلف المدخلات والإضافات.

| الخاصية        | النوع                          | الوصف                                      |
| ----------- | ----------------------------- | ------------------------------------------------ |
| `className` | `string`                      | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | `React.ComponentProps<'div'>` | يتم دعم جميع سمات div القياسية        |

### InputGroupAddon

حاوية للإضافات مثل الرموز والنصوص والأزرار والعناصر الأخرى. يمكن وضعه في بداية أو نهاية (مضمنة) أو أعلى أو أسفل (كتلة) الإدخال.

| الخاصية        | النوع                                                              | الافتراضي          | الوصف                                                                                                                        |
| ----------- | ----------------------------------------------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `align`     | `'inline-start' \| 'inline-end' \| 'block-start' \| 'block-end'` | `'inline-start'` | موقف الملحق بالنسبة إلى الإدخال. استخدام `inline-start` أو `inline-end` للمدخلات و `block-start` أو `block-end` للمناطق النصية |
| `className` | `string`                                                          |                  | فئات تنسيق إضافية لتخصيص المكوّن.                                                                                   |
| `...props`  | `React.ComponentProps<'div'>`                                     |                  | يتم دعم جميع سمات div القياسية                                                                                          |

<Alert className="bg-muted/24">
  <InfoIcon />
  <AlertDescription>
    للملاحة التركيز السليم، `InputGroupAddon` يجب وضع المكون بعد الإدخال في ترتيب بنية الصفحة.
  </AlertDescription>
</Alert>

### InputGroupText

مكون حاوية نصية لعرض محتوى النص داخل `InputGroupAddon`. تلقائيا أنماط النص مع لون المقدمة صامتة ومقابض رمز التحجيم.

| الخاصية        | النوع                           | الوصف                                      |
| ----------- | ------------------------------ | ------------------------------------------------ |
| `className` | `string`                       | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | `React.ComponentProps<'span'>` | يتم دعم جميع سمات الامتداد القياسية       |

### InputGroupInput

مكون إدخال متخصص للاستخدام داخل InputGroup. إنه في الأساس مكون إدخال غير مصنف يرث التصميم من InputGroup الأم.

| الخاصية        | النوع         | الوصف                                                                                           |
| ----------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| `className` | `string`     | فئات تنسيق إضافية لتخصيص المكوّن.                                                      |
| `...props`  | `InputProps` | يتم دعم جميع الدعائم من مكون الإدخال ، بما في ذلك `type`, `placeholder`, `disabled`، إلخ. |

### InputGroupTextarea

مكون نصي متخصص للاستخدام داخل InputGroup. إنه مكون نصي غير مصمم يرث التصميم من الأصل InputGroup.

| الخاصية        | النوع            | الوصف                                                                                              |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------------- |
| `className` | `string`        | فئات تنسيق إضافية لتخصيص المكوّن.                                                         |
| `...props`  | `TextareaProps` | يتم دعم جميع الدعائم من مكون مساحة النص ، بما في ذلك `placeholder`, `disabled`, `rows`، إلخ. |
