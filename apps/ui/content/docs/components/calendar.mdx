## مرجع الواجهة البرمجية

هذا المكون يلتف [@daypicker/react](https://daypicker.dev/) مع التصميم المخصص.

### التقويم

عنصر التقويم لاختيار التاريخ.

| الخاصية              | النوع                                                | الافتراضي    | الوصف                                      |
| ----------------- | --------------------------------------------------- | ---------- | ------------------------------------------------ |
| `mode`            | `"single" \| "multiple" \| "range"`                 | `"single"` | وضع التحديد للتقويم                  |
| `captionLayout`   | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` | تخطيط التسمية التوضيحية - استخدام `"dropdown"` لشهر/سنة المنسدلة |
| `selected`        | `Date \| Date[] \| DateRange`                       | -          | التاريخ المختار (التواريخ)                             |
| `onSelect`        | `(date: Date \| Date[] \| DateRange) => void`       | -          | معاودة الاتصال عند تغيير تحديد التاريخ             |
| `showOutsideDays` | `boolean`                                           | `true`     | إظهار الأيام من الأشهر المجاورة                   |
| `startMonth`      | `Date`                                              | -          | الشهر الأول للعرض في التنقل المنسدلة       |
| `endMonth`        | `Date`                                              | -          | الشهر الماضي لتظهر في التنقل المنسدلة        |
| `buttonVariant`   | `"ghost" \| "outline" \| ...`                       | `"ghost"`  | زر البديل لأزرار التنقل            |
| `classNames`      | `object`                                            | -          | أسماء فئات مخصصة لأجزاء التقويم            |
| `components`      | `object`                                            | -          | مكونات مخصصة لتجاوز الافتراضات           |

للحصول على قائمة كاملة من الدعائم، انظر [@daypicker/react documentation](https://daypicker.dev/).

### تخصيص حجم الخلية

يستخدم التقويم خصائص تنسيق المخصصة لتحجيم الخلية. بشكل افتراضي ، يكون حجم الخلية هو `--spacing(9)` على الهاتف المحمول و `--spacing(8)` على شاشات أكبر:

```css
[--cell-size:--spacing(10)] sm:[--cell-size:--spacing(9)]
```

يمكنك تخصيص حجم الخلية عن طريق تمرير مخصص `className`:

```tsx
<Calendar className="[--cell-size:--spacing(11)]" />
```

أو استخدم قيم الاستجابة:

```tsx
<Calendar className="[--cell-size:--spacing(11)] sm:[--cell-size:--spacing(10)]" />
```
