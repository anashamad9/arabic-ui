## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/input.tsx`. مسار الاستيراد: `@coss/ui/components/input`.

## الاستخدام

```tsx
import { Input } from "@coss/ui/components/input"
```

```tsx
<Input />
```

## مرجع الواجهة البرمجية

### حقل الإدخال

المجمع على غرار ل `Input` من واجهة المستخدم الأساسية مع خيارات حجم مخصص.

| الخاصية       | النوع                                  | الافتراضي     | الوصف                                      |
| ---------- | ------------------------------------- | ----------- | ------------------------------------------------ |
| `size`     | `"sm" \| "default" \| "lg" \| number` | `"default"` | يتحكم في ارتفاع الإدخال. يتم تمرير قيم الأرقام إلى الأصل `size` الخاصية |
| `unstyled` | `boolean`                             | `false`     | عندما يكون صحيحًا ، يزيل تصميم الغلاف (الحدود ، الظل ، إلخ) |

## الأمثلة

للتسميات والتحقق مع دعم سهولة الوصول، يُفضّل استخدام `Field` مكون لتغليف المدخلات ، أو `FieldControl` المكون. انظر بعض [أمثلة ذات صلة](/ui/docs/components/field).
