## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/number-field.tsx`. مسار الاستيراد: `@coss/ui/components/number-field`.

## الاستخدام

```tsx
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldGroup,
  NumberFieldIncrement,
  NumberFieldInput,
  NumberFieldScrubArea,
} from "@coss/ui/components/number-field"
```

```tsx
<NumberField defaultValue={0}>
  <NumberFieldScrubArea label="الكمية" />
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

## مرجع الواجهة البرمجية

### NumberField

المكوّن الأساسي. غلاف منسّق للمكوّن `NumberField.Root` من مكتبة بيس.

| الخاصية   | النوع                        | الافتراضي     | الوصف                                      |
| ------ | --------------------------- | ----------- | ------------------------------------------------ |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | يتحكم في حجم جميع مكونات الطفل عبر السياق |

### NumberFieldGroup

حاوية للإدخال والأزرار. غلاف مصمم ل `NumberField.Group` من مكتبة بيس.

### NumberFieldInput

عنصر الإدخال لقيمة الرقم. غلاف نمطي ل `NumberField.Input` من مكتبة بيس.

### NumberFieldIncrement

زر لزيادة القيمة. غلاف نمط ل `NumberField.Increment` من واجهة المستخدم الأساسية مع رمز زائد.

### NumberFieldDecrement

زر إلى decrement القيمة. غلاف نمط ل `NumberField.Decrement` من واجهة المستخدم الأساسية مع رمز ناقص.

### NumberFieldScrubArea

منطقة قابلة للسحب لغسل القيمة. غلاف مصمم ل `NumberField.ScrubArea` من مكتبة بيس.

| الخاصية    | النوع     | الافتراضي | الوصف                                      |
| ------- | -------- | ------- | ------------------------------------------------ |
| `label` | `string` | -       | نص التسمية المعروض في منطقة فرك           |
