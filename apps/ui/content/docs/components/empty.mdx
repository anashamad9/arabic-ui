## الاستخدام

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty"
```

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <Icon />
    </EmptyMedia>
    <EmptyTitle>لا توجد بيانات</EmptyTitle>
    <EmptyDescription>لم يتم العثور على بيانات</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button>إضافة بيانات</Button>
  </EmptyContent>
</Empty>
```

## مرجع الواجهة البرمجية

تم تصميم تصميم واجهة برمجية لهذا المكون بعد [مكون shadcn / ui الفارغ](https://ui.shadcn.com/docs/components/empty) لضمان الألفة والاتساق للمطورين الذين يستخدمون بالفعل شادسي إن. هذا التوحيد يجعل من السهل اعتماد **COSS UI/Arabic** مع الحفاظ على التكافؤ واجهة برمجية مع أنماط المطورين يعرفون بالفعل والحب.

### الحالة الفارغة

المكون الرئيسي للدولة فارغة. يلتف `EmptyHeader` و `EmptyContent` المكونات.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<Empty>
  <EmptyHeader />
  <EmptyContent />
</Empty>
```

### EmptyHeader

المكوّن `EmptyHeader` يلف المكون الوسائط الفارغة والعنوان والوصف.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<EmptyHeader>
  <EmptyMedia />
  <EmptyTitle />
  <EmptyDescription />
</EmptyHeader>
```

### EmptyMedia

استخدم `EmptyMedia` مكون لعرض وسائط الحالة الفارغة مثل أيقونة أو صورة. يمكنك أيضًا استخدامه لعرض مكونات أخرى مثل الصورة الشخصية.

| الخاصية        | النوع                  | الافتراضي   |
| ----------- | --------------------- | --------- |
| `variant`   | `"default" \| "icon"` | `default` |
| `className` | `string`              |           |

```tsx
<EmptyMedia variant="icon">
  <Icon />
</EmptyMedia>
```

```tsx
<EmptyMedia>
  <Avatar>
    <AvatarImage src="..." />
    <AvatarFallback>م أ</AvatarFallback>
  </Avatar>
</EmptyMedia>
```

### EmptyTitle

استخدم `EmptyTitle` مكون لعرض عنوان الحالة الفارغة.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<EmptyTitle>لا توجد بيانات</EmptyTitle>
```

### EmptyDescription

استخدم `EmptyDescription` المكون لعرض وصف الحالة الفارغة.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<EmptyDescription>ليس لديك أي إشعارات.</EmptyDescription>
```

### EmptyContent

استخدم `EmptyContent` مكون لعرض محتوى الحالة الفارغة مثل زر أو إدخال أو رابط.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<EmptyContent>
  <Button>إضافة مشروع</Button>
</EmptyContent>
```
