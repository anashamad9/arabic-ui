## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/radio-group.tsx`. مسار الاستيراد: `@coss/ui/components/radio-group`.

## الاستخدام

```tsx
import { Label } from "@coss/ui/components/label"
import { Radio, RadioGroup } from "@coss/ui/components/radio-group"
```

```tsx
<RadioGroup defaultValue="next">
  <Label>
    <Radio value="next" /> Next.js
  </Label>
  <Label>
    <Radio value="vite" /> فايت
  </Label>
  <Label>
    <Radio value="astro" /> أسترو
  </Label>
</RadioGroup>
```

## مرجع الواجهة البرمجية

### RadioGroup

المكوّن الأساسي. غلاف منسّق للمكوّن `RadioGroup.Root` من واجهة المستخدم الأساسية مع تخطيط العمود المرن.

### اختيار أحادي

زر راديو فردي. غلاف مصمم ل `Radio.Root` من واجهة المستخدم الأساسية مع مؤشر مدمج. كما تصديرها كما `RadioGroupItem`.

## الأمثلة

للتسميات والتحقق مع دعم سهولة الوصول، يُفضّل استخدام `Field` مكون لف أزرار الراديو. انظر المثال ذي الصلة: [حقل الاختيار الأحادي](/ui/docs/components/field#حقل-الاختيار-الأحادي).

للحصول على خيارات حصرية متبادلة على غرار علامات التبويب ، راجع [الاختيار المقسّم](/ui/docs/components/segmented-control) نمط.
