## الرابط

يمكنك استخدام [`render`](https://base-ui.com/react/utils/use-render#migrating-from-radix-ui) الخاصية لجعل مكون آخر يبدو وكأنه شارة. إليك مثال على رابط يشبه شارة.

```tsx
import Link from "next/link"

import { Badge } from "@/components/ui/badge"

export function LinkAsBadge() {
  return <Badge render={<Link href="/pricing" />}>جديد</Badge>
}
```

## مرجع الواجهة البرمجية

مكوّن مخصّص يستخدم من مكتبة بيس `useRender` بدلًا من تغليف مكوّن جاهز مباشرة.

### الشارة

مكون شارة مع خيارات متغيرة وحجم.

| الخاصية      | النوع                                                                                                    | الافتراضي     | الوصف                                      |
| --------- | ------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------ |
| `variant` | `"default" \| "destructive" \| "error" \| "info" \| "outline" \| "secondary" \| "success" \| "warning"` | `"default"` | يتحكم في تصميم الشارة ونظام الألوان      |
| `size`    | `"default" \| "sm" \| "lg"`                                                                             | `"default"` | يتحكم في حجم الشارة                          |
| `render`  | `React.ReactElement`                                                                                    | -           | يعرض عنصرًا مختلفًا، مثل الرابط.       |
