## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/breadcrumb.tsx`. مسار الاستيراد: `@coss/ui/components/breadcrumb`.

## الاستخدام

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@coss/ui/components/breadcrumb"
```

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">الرئيسية</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
    <BreadcrumbItem>
      <BreadcrumbLink href="/components">المكونات</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>مسار التنقل</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## مرجع الواجهة البرمجية

مكوّن مخصّص للمكتبة.

### مسار التنقل

حاوية الملاحة الجذر مع `aria-label="breadcrumb"`.

### BreadcrumbList

حاوية قائمة أمرت لبنود مسار التنقل.

### BreadcrumbItem

حاوية بند مسار التنقل الفردية.

### BreadcrumbLink

عنصر الارتباط لعناصر مسار التنقل القابلة للملاحة. يدعم `render` الخاصية لاستخدام مكونات الارتباط المخصصة (على سبيل المثال، نكست Link).

| الخاصية     | النوع                   | الافتراضي | الوصف                                      |
| -------- | ---------------------- | ------- | ------------------------------------------------ |
| `render` | `React.ReactElement`   | -       | تقديم كعنصر مختلف (على سبيل المثال، نكست Link) |

### BreadcrumbPage

عنصر غير تفاعلي يمثل الصفحة الحالية. يتضمن `aria-current="page"`.

### BreadcrumbSeparator

فاصل بين عناصر مسار التنقل. الافتراضي إلى رمز شيفرون ولكنه يقبل الأطفال المخصصين.

### BreadcrumbEllipsis

مؤشر القطع الناقص لعناصر مسار التنقل المنهارة.
