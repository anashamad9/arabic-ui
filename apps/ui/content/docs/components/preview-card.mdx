## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/preview-card.tsx`. مسار الاستيراد: `@coss/ui/components/preview-card`.

## الاستخدام

```tsx
import { Button } from "@coss/ui/components/button"
import {
  PreviewCard,
  PreviewCardPopup,
  PreviewCardTrigger,
} from "@coss/ui/components/preview-card"
```

```tsx
<PreviewCard>
  <PreviewCardTrigger>فتح بطاقة معاينة</PreviewCardTrigger>
  <PreviewCardPopup>معاينة محتوى البطاقة</PreviewCardPopup>
</PreviewCard>
```

## مرجع الواجهة البرمجية

### PreviewCard

المكوّن الأساسي. اسم بديل للمكوّن `PreviewCard.Root` من مكتبة بيس.

### PreviewCardTrigger

عنصر عنصر التفعيل الذي يظهر بطاقة المعاينة على تحوم. الاسم المستعار ل `PreviewCard.Trigger` من مكتبة بيس.

### PreviewCardPopup

حاوية منبثقة تعرض محتوى المعاينة. كما تم تصديرها كـ `HoverCardContent`.

| الخاصية          | النوع                           | الافتراضي    | الوصف                                      |
| ------------- | ------------------------------ | ---------- | ------------------------------------------------ |
| `align`       | `"start" \| "center" \| "end"` | `"center"` | محاذاة بالنسبة إلى عنصر التفعيل                |
| `sideOffset`  | `number`                       | `4`        | المسافة من عنصر التفعيل بالبكسل              |
| `portalProps` | `PreviewCard.Portal.Props`     | -          | خصائص تُمرّر إلى البوابة الداخلية (`keepMounted`, `container`، وما إلى ذلك) ؛ انظر قاعدة واجهة المستخدم معاينة بطاقة واجهة برمجة التطبيقات |
