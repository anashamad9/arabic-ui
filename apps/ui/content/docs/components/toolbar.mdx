## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/toolbar.tsx`. مسار الاستيراد: `@coss/ui/components/toolbar`.

## الاستخدام

```tsx
import { Button } from "@coss/ui/components/button"
import { Toggle } from "@coss/ui/components/toggle"
import {
  Toolbar,
  ToolbarButton,
  ToolbarGroup,
  ToolbarSeparator,
} from "@coss/ui/components/toolbar"
```

```tsx
<Toolbar>
  <ToolbarGroup>
    <ToolbarButton render={<Toggle />}>عريض</ToolbarButton>
    <ToolbarButton render={<Toggle />}>تسطير</ToolbarButton>
  </ToolbarGroup>
  <ToolbarSeparator />
  <ToolbarButton render={<Button />}>حفظ</ToolbarButton>
</Toolbar>
```

## مرجع الواجهة البرمجية

### شريط الأدوات

المكوّن الأساسي. غلاف منسّق للمكوّن `Toolbar.Root` من واجهة المستخدم الأساسية مع تخطيط فليكس.

### ToolbarGroup

عناصر شريط الأدوات ذات الصلة بالمجموعات. غلاف مصمم ل `Toolbar.Group` من مكتبة بيس.

### ToolbarButton

زر داخل شريط الأدوات. الاسم المستعار ل `Toolbar.Button` من قاعدة واجهة المستخدم. استخدام مع `render` الدعامة لجعل كما تبديل أو زر.

### ToolbarSeparator

فاصل بصري بين عناصر شريط الأدوات. غلاف مصمم ل `Toolbar.Separator` من مكتبة بيس.

### ToolbarLink

رابط داخل شريط الأدوات. الاسم المستعار ل `Toolbar.Link` من مكتبة بيس.
