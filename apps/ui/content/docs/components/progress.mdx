## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/progress.tsx`. مسار الاستيراد: `@coss/ui/components/progress`.

## الاستخدام

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@coss/ui/components/progress"
```

```tsx
<Progress value={40} />
```

ملاحظة: إذا قمت بعرض الأطفال في الداخل `Progress`، يجب أن تشمل أيضا `ProgressTrack` و `ProgressIndicator` داخله. بدونها ، لن يتم عرض الشريط. عندما لا يتم توفير أي أطفال ، يتم تقديم مسار ومؤشر افتراضي لك.

## مرجع الواجهة البرمجية

### مؤشر التقدم

المكوّن الأساسي. غلاف منسّق للمكوّن `Progress.Root` من واجهة المستخدم الأساسية. عندما يتم توفير أي أطفال، تلقائيا يجعل المسار والمؤشر.

### ProgressTrack

حاوية المسار لمؤشر التقدم. غلاف على غرار ل `Progress.Track` من مكتبة بيس.

### ProgressIndicator

مؤشر مرئي يوضح التقدم الحالي. غلاف مصمم ل `Progress.Indicator` من مكتبة بيس.

### ProgressLabel

نص التسمية لشريط التقدم. غلاف نمط ل `Progress.Label` من مكتبة بيس.

### ProgressValue

يعرض القيمة الحالية. غلاف نمط ل `Progress.Value` من مكتبة بيس.
