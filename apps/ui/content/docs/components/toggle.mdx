## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/toggle.tsx`. مسار الاستيراد: `@coss/ui/components/toggle`.

## الاستخدام

```tsx
import { Toggle } from "@coss/ui/components/toggle"
```

```tsx
<Toggle>زر التبديل</Toggle>
```

## مرجع الواجهة البرمجية

### زر التبديل

المجمع على غرار ل `Toggle.Root` من واجهة المستخدم الأساسية مع خيارات متغير وحجم.

| الخاصية      | النوع                          | الافتراضي     | الوصف                                      |
| --------- | ----------------------------- | ----------- | ------------------------------------------------ |
| `variant` | `"default" \| "outline"`      | `"default"` | يتحكم في تصميم تبديل                      |
| `size`    | `"default" \| "sm" \| "lg"`   | `"default"` | يتحكم في حجم التبديل                         |
