## الاستخدام

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src="/avatars/01.png" alt="الرمزية للمستخدم" />
  <AvatarFallback>م أ</AvatarFallback>
</Avatar>
```

استخدم `keepMounted` عندما تعتمد الصورة على تحميل كسول أصلي أو مكون صورة محسّن. يبقى التراجع مرئيًا أثناء تحميل الصورة أو إذا فشلت:

```tsx
<Avatar>
  <AvatarImage
    src="/avatars/01.png"
    alt="الرمزية للمستخدم"
    loading="lazy"
    keepMounted
  />
  <AvatarFallback>م أ</AvatarFallback>
</Avatar>
```

## مرجع الواجهة البرمجية

### الصورة الشخصية

المكوّن الأساسي. غلاف منسّق للمكوّن `Avatar.Root` من واجهة المستخدم الأساسية مع الحجم الافتراضي من 32px (8 وحدات) وتقريب التصميم الكامل.

### AvatarImage

عنصر الصورة للرمزية. غلاف نمط ل `Avatar.Image` من قاعدة واجهة المستخدم مع دعم ل `keepMounted` الصور.

### AvatarFallback

يتم عرض المحتوى الاحتياطي عند فشل تحميل الصورة. غلاف مصمم ل `Avatar.Fallback` من قاعدة واجهة المستخدم مع خلفية صامتة.
