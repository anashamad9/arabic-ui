## حول المشروع

التحكم المجزأ هو نمط مرئي ، وليس سلوكًا مستقلًا. يستخدم COSS UI/Arabic نفس العرض التقديمي عبر عدة مكونات مع الحفاظ على الدلالات وتفاعلات لوحة المفاتيح ونموذج الحالة لكل بدائي أساسي.

## اختر البدائية الصحيحة

| النية | استخدم | لماذا لماذا لماذا؟ |
| ------ | --- | --- |
| اختر قيمة واحدة في نموذج | [مجموعة الاختيار الأحادي](/ui/docs/components/radio-group) | يمثل قيمة حصرية متبادلة ويشارك في حالة الشكل. |
| انتقل إلى عنوان رابط أو مسار آخر | روابط الملاحة | يحافظ على سلوك الارتباط ، وتاريخ المتصفح ، و `aria-current`. |
| تطبيق فلتر أو وضع حصري | [مجموعة أزرار التبديل](/ui/docs/components/toggle-group) | يمثل الحالة المضغوطة لإجراء قد يتم تطهيره. |
| التبديل بين الألواح ذات الصلة | [التبويبات](/ui/docs/components/tabs) | يربط كل علامة تبويب بلوحة محتوى مرتبطة. |

اختر البدائية من التفاعل أولاً ، ثم قم بتطبيق تصميم التحكم المجزأ. التشابه البصري وحده ليس سببًا لاستخدام علامات التبويب أو تبديل مجموعة.

## التثبيت

يتم توفير عناصر التحكم المجزأة كجزيئات. قم بتثبيت التنفيذ والحجم الذي يتطابق مع تفاعلك:

| التنفيذ | صغير | الافتراضي | كبير |
| -------------- | ----- | ------- | ----- |
| مجموعة الاختيار الأحادي | `@arabicui/p-radio-group-7` | `@arabicui/p-radio-group-8` | `@arabicui/p-radio-group-9` |
| الملاحة | `@arabicui/p-navigation-2` | `@arabicui/p-navigation-1` | `@arabicui/p-navigation-3` |

على سبيل المثال، قم بتثبيت إصدار اختيار أحادي مجموعة الافتراضي باستخدام:

```bash
npx shadcn@latest add @arabicui/p-radio-group-8
```

تثبيت سطر الأوامر المشتركة `segmented-control` مكتبة التصميم والبدائية المطلوبة تلقائيا.

## التصميم المشترك

للحصول على تكوين مخصص ، قم بتثبيت مكتبة التصميم مباشرة:

```bash
npx shadcn@latest add @arabicui/segmented-control
```

تصدر المكتبة فئة الجذر، وصفة عنصر، وفئة تخطيط عنصر مشترك للرموز:

```tsx
import {
  segmentedControlItemLayoutClassName,
  segmentedControlItemVariants,
  segmentedControlRootClassName,
} from "@/lib/segmented-control"
```

```tsx
const itemClassName = segmentedControlItemVariants({
  size: "default",
  state: "checked",
})
```

| الخيار | قيم | الوصف |
| ------ | ------ | ----------- |
| `size` | `"sm" \| "default" \| "lg"` | يتحكم في ارتفاع البند والحشو الأفقي. |
| `state` | `"checked" \| "current" \| "pressed"` | يحدد سمة الحالة المستخدمة من قبل العنصر الأساسي. |

استخدم `checked` مع راديو جروب، `current` مع وصلات الملاحة، و `pressed` مع تبديل مجموعة. تحتفظ علامات التبويب بمؤشر متحرك خاص بها ولا تستخدم وصفة الحالة المشتركة. يعيدون استخدامها `segmentedControlItemLayoutClassName` لذلك الرموز تطابق تطبيقات مجزأة أخرى.

في الحواف الخارجية ، حشو البند والسطح `p-0.5` تتحد أقحم لتتناسب مع الحشوة الأفقية لحجم الزر المقابل. السطح الخارجي المجزأ أطول قليلاً من ذلك الزر لتحقيق التوازن البصري للعنصر المحدد من أقحم عندما تظهر عناصر التحكم بجوار بعضها البعض.
