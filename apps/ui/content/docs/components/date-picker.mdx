## حول المشروع

تم بناء منتقي التاريخ باستخدام تركيبة من `<Calendar>` و `<Popover>` المكونات.

## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

هذا المثال يجمع عدة مكونات محلية؛ استخدم مسارات الاستيراد الموضحة أدناه.

## الاستخدام

```tsx
import { format } from "date-fns"
import { CalendarIcon } from "lucide-react"
import { useState } from "react"

import { Button } from "@coss/ui/components/button"
import { Calendar } from "@coss/ui/components/calendar"
import {
  Popover,
  PopoverPopup,
  PopoverTrigger,
} from "@coss/ui/components/popover"
```

```tsx
const [date, setDate] = useState<Date>()

return (
  <Popover>
    <PopoverTrigger
      render={
        <Button
          className="w-[280px] justify-start text-left font-normal"
          variant="outline"
        />
      }
    >
      <CalendarIcon />
      {date ? format(date, "PPP") : <span>اختر تاريخًا</span>}
    </PopoverTrigger>
    <PopoverPopup align="start" className="w-auto p-0">
      <Calendar mode="single" selected={date} onSelect={setDate} />
    </PopoverPopup>
  </Popover>
)
```
