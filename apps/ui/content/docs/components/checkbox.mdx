## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/checkbox.tsx`. مسار الاستيراد: `@coss/ui/components/checkbox`.

## الاستخدام

```tsx
import { Checkbox } from "@coss/ui/components/checkbox"
```

```tsx
<Checkbox />
```

## مرجع الواجهة البرمجية

### مربع الاختيار

المجمع على غرار ل `Checkbox.Root` من واجهة المستخدم الأساسية. يتضمن مؤشر مدمج مع علامة اختيار ورموز غير محددة.

## الأمثلة

للتسميات والتحقق مع دعم سهولة الوصول، يُفضّل استخدام `Field` مكون لتغليف مربعات الاختيار. انظر المثال ذي الصلة: [حقل خانة الاختيار](/ui/docs/components/field#حقل-خانة-الاختيار).
