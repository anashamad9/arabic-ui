## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/table.tsx`. مسار الاستيراد: `@coss/ui/components/table`.

## الاستخدام

```tsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@coss/ui/components/table"
```

```tsx
<Table>
  <TableCaption>التسمية التوضيحية</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead>العنوان</TableHead>
      <TableHead>العنوان</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>الخلية</TableCell>
      <TableCell>الخلية</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## مرجع الواجهة البرمجية

### الجدول

عنصر حاوية الجدول الرئيسي. تعيين `variant="card"` لطاولة على غرار بطاقة: الحدود المنفصلة، زوايا مدورة، والأسطح الصف التي تقرأ كبطاقات. أن أزواج بشكل جيد مع [الإطار](/ui/docs/components/frame) (صفحة الكروم) أو [CardFrame](/ui/docs/components/card) (قذيفة بطاقة مع إجراءات رأس اختيارية). البديل الافتراضي هو تخطيط صف أبسط مع حدود قياسية.

| الخاصية        | النوع                         | الافتراضي     |
| ----------- | ---------------------------- | ----------- |
| `className` | `string`                     |             |
| `variant`   | `"default"` \| `"card"`      | `"default"` |

```tsx
<Table>
  <TableHeader>...</TableHeader>
  <TableBody>...</TableBody>
</Table>
```

```tsx
<Table variant="card">
  <TableHeader>...</TableHeader>
  <TableBody>...</TableBody>
</Table>
```

### TableHeader

قسم الرأس في الجدول الذي يحتوي على رؤوس الأعمدة.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<TableHeader>
  <TableRow>
    <TableHead>العنوان</TableHead>
  </TableRow>
</TableHeader>
```

### TableBody

قسم الجسم من الجدول الذي يحتوي على صفوف الجدول والبيانات.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<TableBody>
  <TableRow>
    <TableCell>الخلية</TableCell>
  </TableRow>
</TableBody>
```

### TableFooter

قسم تذييل من الطاولة.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<TableFooter>
  <TableRow>
    <TableCell>التذييل</TableCell>
  </TableRow>
</TableFooter>
```

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |

```tsx

  <TableCell>الخلية</TableCell>

```

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |

## الأمثلة

### طاولة على غرار البطاقة

استخدم `variant="card"` عندما الشبكة نفسها يجب أن تبدو وكأنها مجموعة من البطاقات (على سبيل المثال لوحات المعلومات أو الجداول المستقلة دون إطار خارجي).

<ComponentPreview name="p-table-5" />

### الجدول في إطار البطاقة

ضع الطاولة في [CardFrame](/ui/docs/components/card) حتى الشبكة يجلس داخل قذيفة بطاقة (الحدود، دائرة نصف قطرها، لقطة). استخدام `variant="card"` على `Table`. المثال أدناه هو ترميز ثابت - لا يوجد تحديد صف أو TanStack.

<ComponentPreview name="p-table-7" />

### الجدول في الإطار

لف الطاولة في a [الإطار](/ui/docs/components/frame) لحدود التطبيق سطح تأطير. استخدام `variant="card"` على `Table` حتى الصفوف الحفاظ على العلاج على غرار بطاقة داخل الإطار.

<ComponentPreview name="p-table-2" />

### جدول البيانات مع تانستاك

استخدم [جدول البيانات](https://tanstack.com/table) مع `variant="card"` عندما تحتاج إلى تعريفات الأعمدة ، وتحديد الصفوف ، و `flexRender` على نفس الجدول الأوليات. إضافة `@tanstack/react-table` لمشروعك لحالة مقطوعة الرأس (الفرز ، ترقيم الصفحات ، التحديد) بعد الترميز الثابت.

<ComponentPreview name="p-table-6" />
