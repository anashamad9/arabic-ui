## الاستخدام

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@/components/ui/accordion"
```

```tsx
<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger>هل يمكن الوصول إليها؟</AccordionTrigger>
    <AccordionPanel>
      نعم. إنها تلتزم بنمط تصميم سهولة الوصول.
    </AccordionPanel>
  </AccordionItem>
</Accordion>
```

## مرجع الواجهة البرمجية

### القائمة القابلة للطي

المكوّن الأساسي. اسم بديل للمكوّن `Accordion.Root` من مكتبة بيس.

### AccordionItem

حاوية البند القائمة القابلة للطي الفردية. المجمع على غرار ل `Accordion.Item` من واجهة المستخدم الأساسية مع تصميم الحدود السفلية.

### AccordionTrigger

زر عنصر التفعيل الذي يحرك لوحة القائمة القابلة للطي. غلاف مصمم ل `Accordion.Trigger` من واجهة المستخدم الأساسية. يتضمن رمز شيفرون مدمج يدور عند توسيعه.

### AccordionPanel

لوحة محتوى قابلة للطي. غلاف مصمم ل `Accordion.Panel` من واجهة المستخدم الأساسية مع التحولات ارتفاع الرسوم المتحركة. أيضا تصديرها كما `AccordionContent`.
