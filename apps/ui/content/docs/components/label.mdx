## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/label.tsx`. مسار الاستيراد: `@coss/ui/components/label`.

## الاستخدام

```tsx
import { Label } from "@coss/ui/components/label"
```

```tsx
<Label htmlFor="email">البريد الإلكتروني</Label>
```

## مرجع الواجهة البرمجية

مكوّن مخصّص يستخدم من مكتبة بيس `useRender` بدلًا من تغليف مكوّن جاهز مباشرة.

### التسمية

مكون التسمية الذي يمكن تقديمه كعناصر مختلفة.

| الخاصية     | النوع                   | الافتراضي | الوصف                                      |
| -------- | ---------------------- | ------- | ------------------------------------------------ |
| `render` | `React.ReactElement`   | -       | تقديم كعنصر مختلف                    |

## الأمثلة

للتسميات والتحقق مع دعم سهولة الوصول، يُفضّل استخدام `FieldLabel` المكون. انظر بعض [أمثلة ذات صلة](/ui/docs/components/field).
