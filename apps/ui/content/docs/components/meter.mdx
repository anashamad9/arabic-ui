## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/meter.tsx`. مسار الاستيراد: `@coss/ui/components/meter`.

## الاستخدام

```tsx
import { Meter, MeterLabel, MeterValue } from "@coss/ui/components/meter"
```

```tsx
<Meter value={40}>
  <MeterLabel>مؤشر التقدم</MeterLabel>
  <MeterValue />
</Meter>
```

## مرجع الواجهة البرمجية

### مقياس القيمة

المكوّن الأساسي. غلاف منسّق للمكوّن `Meter.Root` من واجهة المستخدم الأساسية مع تخطيط العمود المرن.

### MeterTrack

حاوية المسار لمؤشر متر. المجمع على غرار ل `Meter.Track` من مكتبة بيس.

### MeterIndicator

مؤشر مرئي يوضح القيمة الحالية. غلاف مصمم ل `Meter.Indicator` من مكتبة بيس.

### MeterLabel

نص التسمية للمتر. المجمع على غرار ل `Meter.Label` من مكتبة بيس.

### MeterValue

يعرض القيمة الحالية. غلاف نمط ل `Meter.Value` من مكتبة بيس.
