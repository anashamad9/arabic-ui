## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/toggle-group.tsx`. مسار الاستيراد: `@coss/ui/components/toggle-group`.

## الاستخدام

```tsx
import { ToggleGroup, ToggleGroupItem } from "@coss/ui/components/toggle-group"
```

```tsx
<ToggleGroup>
  <ToggleGroupItem>عريض</ToggleGroupItem>
  <ToggleGroupItem>مائل</ToggleGroupItem>
  <ToggleGroupItem>تسطير</ToggleGroupItem>
</ToggleGroup>
```

## مرجع الواجهة البرمجية

### ToggleGroup

المكوّن الأساسي. غلاف منسّق للمكوّن `ToggleGroup.Root` من واجهة المستخدم الأساسية. يوفر البديل المشترك والحجم إلى تبديلات الطفل عبر السياق.

| الخاصية      | النوع                          | الافتراضي     | الوصف                                      |
| --------- | ----------------------------- | ----------- | ------------------------------------------------ |
| `variant` | `"default" \| "outline"`      | `"default"` | يتحكم في تصميم جميع تبديلات الأطفال        |
| `size`    | `"default" \| "sm" \| "lg"`   | `"default"` | يتحكم في حجم جميع تبديلات الأطفال           |

### ToggleGroupItem

زر تبديل الفردية داخل المجموعة. المجمع على غرار ل `Toggle` من واجهة المستخدم الأساسية. يرث البديل والحجم من سياق ToggleGroup الأم.

### ToggleGroupSeparator

فاصل بصري بين أزرار التبديل.
