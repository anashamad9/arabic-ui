## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/checkbox-group.tsx`. مسار الاستيراد: `@coss/ui/components/checkbox-group`.

## الاستخدام

```tsx
import { Checkbox } from "@coss/ui/components/checkbox"
import { CheckboxGroup } from "@coss/ui/components/checkbox-group"
```

```tsx
<CheckboxGroup>
  <Label>
    <Checkbox defaultChecked />
    Next.js
  </Label>
  <Label>
    <Checkbox />
    فايت
  </Label>
  <Label>
    <Checkbox />
    أسترو
  </Label>
</CheckboxGroup>
```

## مرجع الواجهة البرمجية

### CheckboxGroup

المجمع على غرار ل `CheckboxGroup` من واجهة المستخدم الأساسية. يوفر إدارة الحالة المشتركة لمجموعة من خانات الاختيار مع تخطيط العمود المرن.

## الأمثلة

للحصول على علامات المجموعة والتحقق من صحتها ، تفضل تغليف مجموعات مربع الاختيار مع `Field` و `Fieldset`. انظر المثال ذي الصلة: [حقل مجموعة مربع الاختيار](/ui/docs/components/field#خانة-الاختيار-حقل-المجموعة).
