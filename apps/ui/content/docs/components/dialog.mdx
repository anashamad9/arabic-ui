## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/dialog.tsx`. مسار الاستيراد: `@coss/ui/components/dialog`.

## الاستخدام

```tsx
import {
  Dialog,
  DialogClose,
  DialogDescription,
  DialogPanel,
  DialogFooter,
  DialogHeader,
  DialogPopup,
  DialogTitle,
  DialogTrigger,
} from "@coss/ui/components/dialog"
```

```tsx
<Dialog>
  <DialogTrigger>فتح النافذة</DialogTrigger>
  <DialogPopup>
    <DialogHeader>
      <DialogTitle>عنوان الحوار</DialogTitle>
      <DialogDescription>الحوار الوصف</DialogDescription>
    </DialogHeader>
    <DialogPanel>المحتوى</DialogPanel>
    <DialogFooter>
      <DialogClose>إغلاق</DialogClose>
    </DialogFooter>
  </DialogPopup>
</Dialog>
```

## مرجع الواجهة البرمجية

### النافذة الحوارية

المكوّن الأساسي. اسم بديل للمكوّن `Dialog.Root` من مكتبة بيس.

### DialogTrigger

زر عنصر التفعيل الذي يفتح الحوار. الاسم المستعار ل `Dialog.Trigger` من مكتبة بيس.

### DialogCreateHandle

ينشئ مقبضًا لمشغلات الحوار المنفصلة. استخدمه عندما يحتاج المشغل والمنبثق إلى التنسيق عبر أجزاء مختلفة من الشجرة.

### DialogPopup

حاوية منبثقة تعرض محتوى الحوار. كما تم تصديرها كـ `DialogContent`.

| الخاصية                  | النوع                        | الافتراضي | الوصف                                      |
| --------------------- | --------------------------- | ------- | ------------------------------------------------ |
| `showCloseButton`     | `boolean`                   | `true`  | عندما يكون الأمر صحيحًا ، يعرض زر إغلاق في الزاوية العلوية اليمنى |
| `bottomStickOnMobile` | `boolean`                   | `true`  | عندما يكون ذلك صحيحًا ، يلتصق بأسفل الشاشة على الأجهزة المحمولة |
| `closeProps`          | `Dialog.Close.Props`        | -       | الدعائم إعادة توجيهها إلى زر الإغلاق الداخلي ، مفيدة لتجاوز `aria-label` |
| `portalProps`         | `Dialog.Portal.Props`       | -       | خصائص تُمرّر إلى البوابة الداخلية (`keepMounted`, `container`، وما إلى ذلك) ؛ انظر قاعدة واجهة المستخدم الحوار بوابة واجهة برمجية |

### DialogHeader

حاوية لعنوان الحوار والوصف. يدعم `render` الدعامة لتكوين متعدد الأشكال (على سبيل المثال `render={<Link href="/" />}`).

### DialogFooter

قسم تذييل لأزرار العمل. يدعم `render` الخاصية لتركيب العناصر بأشكال مختلفة.

| الخاصية        | النوع                     | الافتراضي     | الوصف                                      |
| ----------- | ------------------------ | ----------- | ------------------------------------------------ |
| `variant`   | `"default" \| "bare"`    | `"default"` | يتحكم في تصميم التذييل. `default` تشمل الحدود والخلفية ، `bare` يزيلها |

**مثال:**

```tsx
// Default variant (with border and background)
<DialogFooter>
  <DialogClose>إلغاء</DialogClose>
  <Button>حفظ</Button>
</DialogFooter>

// Bare variant (no border or background)
<DialogFooter variant="bare">
  <DialogClose>إلغاء</DialogClose>
  <Button>حفظ</Button>
</DialogFooter>
```

### DialogTitle

عنصر العنوان. الاسم المستعار ل `Dialog.Title` من مكتبة بيس.

### DialogDescription

عنصر الوصف. الاسم المستعار ل `Dialog.Description` من مكتبة بيس.

### DialogPanel

حاوية محتوى قابلة للتمرير. يلف المحتوى تلقائيًا في `ScrollArea` عنصر. يدعم `render` الخاصية لتركيب العناصر بأشكال مختلفة.

| الخاصية         | النوع      | الافتراضي | الوصف                                      |
| ------------ | --------- | ------- | ------------------------------------------------ |
| `scrollFade` | `boolean` | `true`  | عندما يكون صحيحًا ، يظهر تأثير تتلاشى على حواف التمرير   |

**مثال:**

```tsx
<DialogPanel>
  {/* Long content that will scroll if it exceeds the dialog height */}
  <div>...</div>
</DialogPanel>
```

### DialogClose

إغلاق زر المكون. الاسم المستعار ل `Dialog.Close` من مكتبة بيس.

### DialogPortal

مكون البوابة للعرض خارج التسلسل الهرمي بنية الصفحة. الاسم المستعار ل `Dialog.Portal` من مكتبة بيس.

### DialogBackdrop

خلفية / عنصر تراكب. أيضا تصديرها كما `DialogOverlay`. الاسم المستعار ل `Dialog.Backdrop` من مكتبة بيس.

### DialogViewport

عنصر منطقة العرض لتحديد المواقع. الاسم المستعار ل `Dialog.Viewport` من مكتبة بيس.
