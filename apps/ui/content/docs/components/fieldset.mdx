## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/fieldset.tsx`. مسار الاستيراد: `@coss/ui/components/fieldset`.

## الاستخدام

```tsx
import { Fieldset, FieldsetLegend } from "@coss/ui/components/fieldset"
```

```tsx
<Fieldset>
  <FieldsetLegend>أسطورة فيلدسيت</FieldsetLegend>
</Fieldset>
```

## مرجع الواجهة البرمجية

### مجموعة الحقول

المكوّن الأساسي. غلاف منسّق للمكوّن `Fieldset.Root` من واجهة المستخدم الأساسية مع تخطيط العمود المرن.

### FieldsetLegend

أسطورة لمجموعة الحقول. غلاف نمط ل `Fieldset.Legend` من واجهة المستخدم الأساسية مع وزن الخط شبه الجريء.
