## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/textarea.tsx`. مسار الاستيراد: `@coss/ui/components/textarea`.

## الاستخدام

```tsx
import { Textarea } from "@coss/ui/components/textarea"
```

```tsx
<Textarea />
```

## التكامل الميداني

على عكس عناصر التحكم في النموذج المدمجة في بيس ، لا يوفر بيس إصدارًا بدائيًا أصليًا. يلف هذا المكون الأصلي `<textarea>` عنصر في `Field.Control` داخليًا ، لذلك يتكامل مع `Field` افتراضيًا - لا حاجة لتغليفه في `FieldControl` يدويا.

```tsx
<Field>
  <FieldLabel>الحيوية</FieldLabel>
  <Textarea placeholder="أخبرنا عن نفسك..." />
  <FieldDescription>اكتب سيرة ذاتية قصيرة.</FieldDescription>
  <FieldError>هذا الحقل مطلوب.</FieldError>
</Field>
```

## مرجع الواجهة البرمجية

### مساحة النص

تصميم عنصر مساحة النص الأصلي مع خيارات حجم مخصص.

| الخاصية       | النوع                                  | الافتراضي     | الوصف                                      |
| ---------- | ------------------------------------- | ----------- | ------------------------------------------------ |
| `size`     | `"sm" \| "default" \| "lg" \| number` | `"default"` | يتحكم في حشوة النص. يتم تمرير قيم الأرقام إلى اللغة الأصلية `rows` الخاصية |
| `unstyled` | `boolean`                             | `false`     | عندما يكون صحيحًا ، يزيل كل التصميم الافتراضي           |
