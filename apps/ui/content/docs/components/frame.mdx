## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/frame.tsx`. مسار الاستيراد: `@coss/ui/components/frame`.

## الاستخدام

```tsx
import {
  Frame,
  FrameDescription,
  FrameFooter,
  FrameHeader,
  FramePanel,
  FrameTitle,
} from "@coss/ui/components/frame"
```

```tsx
<Frame>
  <FrameHeader>
    <FrameTitle>العنوان</FrameTitle>
    <FrameDescription>الوصف</FrameDescription>
  </FrameHeader>
  <FramePanel>المحتوى</FramePanel>
  <FrameFooter>التذييل</FrameFooter>
</Frame>
```

## مرجع الواجهة البرمجية

### الإطار

عنصر الحاوية الرئيسي لتجميع المعلومات ذات الصلة.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

### FramePanel

حاوية لوحة لمحتوى الإطار.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FramePanel>المحتوى</FramePanel>
```

### FrameHeader

قسم الرأس للإطار.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FrameHeader>
  <FrameTitle>العنوان</FrameTitle>
  <FrameDescription>الوصف</FrameDescription>
</FrameHeader>
```

### FrameTitle

عنوان النص لرأس الإطار.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FrameTitle>العنوان</FrameTitle>
```

### FrameDescription

وصف النص لرأس الإطار.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FrameDescription>الوصف</FrameDescription>
```

### FrameFooter

قسم تذييل للإطار.

| الخاصية        | النوع     | الافتراضي |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FrameFooter>التذييل</FrameFooter>
```
