## الاستخدام

```tsx
import {
  Collapsible,
  CollapsiblePanel,
  CollapsibleTrigger,
} from "@/components/ui/collapsible"
```

```tsx
<Collapsible>
  <CollapsibleTrigger>هل يمكنني الوصول إلى الملف في السحابة؟</CollapsibleTrigger>
  <CollapsiblePanel>
    نعم، يمكنك الوصول إلى الملف في السحابة.
  </CollapsiblePanel>
</Collapsible>
```

## مرجع الواجهة البرمجية

### المحتوى القابل للطي

المكوّن الأساسي. اسم بديل للمكوّن `Collapsible.Root` من مكتبة بيس.

### CollapsibleTrigger

زر عنصر التفعيل الذي تبديل لوحة قابلة للطي. غلاف مصمم ل `Collapsible.Trigger` من مكتبة بيس.

### CollapsiblePanel

لوحة محتوى قابلة للطي. غلاف مصمم ل `Collapsible.Panel` من واجهة المستخدم الأساسية مع التحولات ارتفاع الرسوم المتحركة. أيضا تصديرها كما `CollapsibleContent`.
