## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/skeleton.tsx`. مسار الاستيراد: `@coss/ui/components/skeleton`.

## الاستخدام

```tsx
import { Skeleton } from "@coss/ui/components/skeleton"
```

```tsx
<Skeleton className="size-10 rounded-full" />
```

## مرجع الواجهة البرمجية

مكوّن مخصّص للمكتبة.

### هيكل التحميل

قرص بسيط مع تأثير نبض متحرك لحالات التحميل. تطبيق التحجيم والشكل عبر className.
