## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/spinner.tsx`. مسار الاستيراد: `@coss/ui/components/spinner`.

## الاستخدام

```tsx
import { Spinner } from "@coss/ui/components/spinner"
```

```tsx
<Spinner />
```
