## الاستخدام

```tsx
import {
  Field,
  FieldDescription,
  FieldError,
  FieldLabel,
  FieldValidity,
} from "@/components/ui/field"
import { Input } from "@/components/ui/input"
```

```tsx
<Field>
  <FieldLabel>الاسم</FieldLabel>
  <Input type="text" placeholder="أدخل اسمك" />
  <FieldDescription>مرئية على ملفك الشخصي</FieldDescription>
  <FieldError>الرجاء إدخال اسم صالح</FieldError>
  <FieldValidity>
    {(validity) => (
      {validity.error && <p>{validity.error}</p>}
    )}
  </FieldValidity>
</Field>
```

## مرجع الواجهة البرمجية

### حقل النموذج

المكوّن الأساسي. غلاف منسّق للمكوّن `Field.Root` من واجهة المستخدم الأساسية مع تخطيط العمود المرن.

### FieldLabel

تسمية للحقل. غلاف نمط ل `Field.Label` من مكتبة بيس.

### FieldItem

حاوية للعناصر الميدانية. غلاف على غرار `Field.Item` من مكتبة بيس.

### FieldDescription

وصف النص للحقل. المجمع على غرار ل `Field.Description` من واجهة المستخدم الأساسية مع لون المقدمة صامتة.

### FieldError

رسالة خطأ للحقل. غلاف مصمم ل `Field.Error` من واجهة المستخدم الأساسية مع لون المقدمة المدمرة.

### FieldControl

الاسم المستعار `Field.Control` من واجهة المستخدم الأساسية. استخدم هذا لتسجيل عنصر تحكم مخصص أو طرف ثالث في سياق الحقل حتى يشارك في وضع العلامات والتحقق من الصحة وحالة الخطأ.

لاحظ أن `Textarea` لا يتطلب `FieldControl` — إنه يلتف `Field.Control` داخليًا ويتكامل مع `Field` بنفس الطريقة `Input` وغيرها من الضوابط المدمجة تفعل.

### FieldValidity

الاسم المستعار `Field.Validity` من مكتبة بيس.
