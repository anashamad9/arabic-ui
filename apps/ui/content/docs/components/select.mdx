## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/select.tsx`. مسار الاستيراد: `@coss/ui/components/select`.

## الاستخدام

```tsx
import {
  Select,
  SelectItem,
  SelectPopup,
  SelectLabel,
  SelectTrigger,
  SelectValue,
} from "@coss/ui/components/select"
```

```tsx
const items = [
  { label: "اختر إطار العمل", value: null },
  { label: "Next.js", value: "next" },
  { label: "فايت", value: "vite" },
  { label: "أسترو", value: "astro" },
]

<Select items={items}>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectPopup>
    <SelectLabel>الأطر</SelectLabel>
    {items.map((item) => (
      <SelectItem key={item.value} value={item}>
        {item.label}
      </SelectItem>
    ))}
  </SelectPopup>
  </Select>
```

## مرجع الواجهة البرمجية

### الاختيار

المكوّن الأساسي. اسم بديل للمكوّن `Select.Root` من مكتبة بيس.

### SelectTrigger

زر عنصر التفعيل الذي يفتح القائمة المنسدلة حدد. غلاف نمط ل `Select.Trigger` من مكتبة بيس.

| الخاصية   | النوع                        | الافتراضي     | الوصف                                      |
| ------ | --------------------------- | ----------- | ------------------------------------------------ |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | يتحكم في حجم عنصر التفعيل                 |

### SelectValue

يعرض القيمة المحددة. غلاف مصمم ل `Select.Value` من مكتبة بيس.

### SelectPopup

حاوية منبثقة لخيارات محددة. أيضا تصديرها كما `SelectContent`.

| الخاصية                   | النوع                    | الافتراضي | الوصف                                                                                         |
| ---------------------- | ----------------------- | ------- | --------------------------------------------------------------------------------------------------- |
| `alignItemWithTrigger` | `boolean`               | `true`  | محاذاة العنصر المحدد مع عنصر التفعيل                                                           |
| `sideOffset`           | `number`                | `4`     | المسافة من عنصر التفعيل بالبكسل                                                                   |
| `portalProps`          | `Select.Portal.Props`   | -       | خصائص تُمرّر إلى البوابة الداخلية (`keepMounted`, `container`، إلخ) ؛ راجع بيس اختيار بوابة العرض واجهة برمجية |

### SelectItem

خيار اختيار فردي. غلاف مصمم ل `Select.Item` من واجهة المستخدم الأساسية مع مؤشر مدمج.

### SelectGroup

العناصر المحددة ذات الصلة بالمجموعات. الاسم المستعار ل `Select.Group` من مكتبة بيس.

### SelectLabel

تسمية لجميع الخيارات في النافذة المنبثقة. غلاف نمط ل `Select.Label` من واجهة المستخدم الأساسية. النقر عليه يركز على المشغل المحدد دون فتح النافذة المنبثقة.

### SelectGroupLabel

تسمية لمجموعة مختارة. غلاف مصمم ل `Select.GroupLabel` من مكتبة بيس.

### SelectSeparator

فاصل البصرية بين العناصر. المجمع على غرار ل `Select.Separator` من مكتبة بيس.

### SelectButton

زر مستقل على غرار مثل `SelectTrigger`. استخدمه كـ `render` الدعامة على مكونات عنصر التفعيل الأخرى (على سبيل المثال ، `ComboboxTrigger`, `MenuTrigger`) لمنحهم مظهر يشبه الاختيار.

| الخاصية   | النوع                        | الافتراضي     | الوصف                                      |
| ------ | --------------------------- | ----------- | ------------------------------------------------ |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | يتحكم في حجم الزر                 |

```tsx
import { SelectButton } from "@coss/ui/components/select"
```

```tsx
<ComboboxTrigger render={<SelectButton />}>
  <ComboboxValue placeholder="اختر فاكهة" />
</ComboboxTrigger>
```
