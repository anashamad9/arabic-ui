## الاستخدام

```tsx
import {
  Autocomplete,
  AutocompleteEmpty,
  AutocompleteInput,
  AutocompleteItem,
  AutocompleteList,
  AutocompletePopup,
} from "@/components/ui/autocomplete"
```

```tsx
const items = [
  { value: "apple", label: "تفاح" },
  { value: "banana", label: "موز" },
  { value: "orange", label: "برتقال" },
  { value: "grape", label: "عنب" },
]

<Autocomplete items={items}>
  <AutocompleteInput placeholder="ابحث…" />
  <AutocompletePopup>
    <AutocompleteEmpty>لم يتم العثور على نتائج.</AutocompleteEmpty>
    <AutocompleteList>
      {(item) => <AutocompleteItem key={item.value} value={item}>{item.label}</AutocompleteItem>}
    </AutocompleteList>
  </AutocompletePopup>
</Autocomplete>
```

## مرجع الواجهة البرمجية

### الإكمال التلقائي

مكون الإكمال التلقائي الجذر. يدير حالة الإكمال التلقائي ويوفر السياق لمكونات الطفل.

| الخاصية       | النوع                                      | الوصف                                         |
| ---------- | ----------------------------------------- | --------------------------------------------------- |
| `items`    | `readonly unknown[]`                      | مجموعة من العناصر لعرضها في الإكمال التلقائي   |
| `open`     | `boolean`                                 | يتحكم في ما إذا كانت النافذة المنبثقة مفتوحة                  |
| `...props` | `React.ComponentProps<typeof Autocomplete>` | يتم دعم جميع الدعائم الإكمال التلقائي لواجهة المستخدم الأساسية        |

### AutocompleteInput

مكون حقل الإدخال مع ميزات موسعة لمتغيرات الحجم ودعم الإضافة.

| الخاصية           | النوع                              | الافتراضي     | الوصف                                                                                      |
| -------------- | --------------------------------- | ----------- | ------------------------------------------------------------------------------------------------ |
| `size`         | `"sm" \| "default" \| "lg"`       | `"default"` | حجم متغير من حقل الإدخال                                                              |
| `startAddon`   | `React.ReactNode`                 | -           | عنصر لعرضه في بداية (الجانب الأيسر) من الإدخال، مثل أيقونة                        |
| `showTrigger`  | `boolean`                         | `false`     | سواء لعرض زر عنصر التفعيل (رمز شيفرون) على الجانب الأيمن من الإدخال                |
| `showClear`    | `boolean`                         | `false`     | سواء لعرض زر واضح (رمز إكس) على الجانب الأيمن من الإدخال عندما تكون هناك قيمة |
| `triggerProps`  | `Autocomplete.Trigger.Props`     | -           | الدعائم إعادة توجيهها إلى زر عنصر التفعيل الداخلي ، مفيدة لتجاوز `aria-label`               |
| `clearProps`    | `Autocomplete.Clear.Props`       | -           | الدعائم إعادة توجيهها إلى زر الداخلية واضحة، مفيدة لتجاوز `aria-label`                 |
| `className`    | `string`                          | -           | فئات تنسيق إضافية لتخصيص المكوّن.                                                 |
| `...props`     | قاعدة واجهة المستخدم الإكمال التلقائي الإدخال الدعائم  | -           | يتم دعم جميع سمات الإدخال الإكمال التلقائي القياسية                                         |

### AutocompletePopup

الحاوية المنبثقة التي تعرض اقتراحات الإكمال التلقائي.

| الخاصية           | النوع                                          | الوصف                                      |
| -------------- | --------------------------------------------- | ------------------------------------------------ |
| `className`    | `string`                                      | فئات تنسيق إضافية لتخصيص المكوّن. |
| `portalProps`  | `Autocomplete.Portal.Props`                   | خصائص تُمرّر إلى البوابة الداخلية (`keepMounted`, `container`، وما إلى ذلك) ؛ راجع بيس اختيار مع البحث بوابة العرض واجهة برمجية (الإكمال التلقائي يعيد استخدامه) |
| `...props`     | قاعدة واجهة المستخدم الإكمال التلقائي الدعائم المنبثقة              | يتم دعم جميع السمات المنبثقة الإكمال التلقائي القياسية |

### AutocompleteList

حاوية قابلة للتمرير لعناصر الإكمال التلقائي.

| الخاصية        | النوع                                     | الوصف                                      |
| ----------- | ---------------------------------------- | ------------------------------------------------ |
| `className` | `string`                                 | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | قاعدة واجهة المستخدم الإكمال التلقائي قائمة الدعائم          | يتم دعم جميع سمات قائمة الإكمال التلقائي القياسية |

### AutocompleteItem

عنصر الإكمال التلقائي الفردي للاختيار.

| الخاصية        | النوع                                     | الوصف                                      |
| ----------- | ---------------------------------------- | ------------------------------------------------ |
| `value`     | `unknown`                                | قيمة البند                            |
| `className` | `string`                                 | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | قاعدة واجهة المستخدم الإكمال التلقائي البند الدعائم          | يتم دعم جميع سمات عنصر الإكمال التلقائي القياسية |

### AutocompleteEmpty

يعرض رسالة عندما لا يتم العثور على نتائج.

| الخاصية        | النوع                                      | الوصف                                      |
| ----------- | ----------------------------------------- | ------------------------------------------------ |
| `className` | `string`                                  | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | قاعدة واجهة المستخدم الإكمال التلقائي الدعائم الفارغة          | يتم دعم جميع سمات الإكمال التلقائي الفارغة القياسية |

### AutocompleteGroup

مجموعات العناصر ذات الصلة الإكمال التلقائي معا.

| الخاصية        | النوع                                      | الوصف                                      |
| ----------- | ----------------------------------------- | ------------------------------------------------ |
| `items`     | `readonly unknown[]`                      | مجموعة العناصر في هذه المجموعة                 |
| `className` | `string`                                  | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | قاعدة واجهة المستخدم الإكمال التلقائي المجموعة الدعائم          | يتم دعم جميع سمات مجموعة الإكمال التلقائي القياسية |

### AutocompleteGroupLabel

يعرض تسمية لمجموعة الإكمال التلقائي.

| الخاصية        | النوع                                           | الوصف                                      |
| ----------- | ---------------------------------------------- | ------------------------------------------------ |
| `className` | `string`                                       | فئات تنسيق إضافية لتخصيص المكوّن. |
| `...props`  | قاعدة واجهة المستخدم الإكمال التلقائي المجموعة تسمية الدعائم         | يتم دعم جميع سمات تسمية مجموعة الإكمال التلقائي القياسية |

### AutocompleteCollection

تستخدم لتغليف العناصر داخل مجموعة لتقديم.

| الخاصية        | النوع                                           | الوصف                                      |
| ----------- | ---------------------------------------------- | ------------------------------------------------ |
| `...props`  | قاعدة واجهة المستخدم الإكمال التلقائي المجموعة الدعائم          | يتم دعم جميع سمات جمع الإكمال التلقائي القياسية |
