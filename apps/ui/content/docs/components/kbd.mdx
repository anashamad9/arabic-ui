## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/kbd.tsx`. مسار الاستيراد: `@coss/ui/components/kbd`.

## الاستخدام

```tsx
import { Kbd, KbdGroup } from "@coss/ui/components/kbd"
```

مفتاح واحد:

```tsx
<Kbd>K</Kbd>
```

مفاتيح متعددة (مفتاح الجمع):

```tsx
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```
