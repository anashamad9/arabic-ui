## الاستخدام

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

مفتاح واحد:

```tsx
<Kbd>K</Kbd>
```

مفاتيح متعددة (مفتاح الجمع):

```tsx
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```
