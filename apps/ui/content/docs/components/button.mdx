## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/button.tsx`. مسار الاستيراد: `@coss/ui/components/button`.

## الاستخدام

```tsx
import { Button } from "@coss/ui/components/button"
```

```tsx
<Button>الزر</Button>
```

## الرابط

يمكنك استخدام [`render`](https://base-ui.com/react/utils/use-render#migrating-from-radix-ui) الخاصية لجعل مكون آخر يبدو وكأنه زر. إليك مثال على رابط يشبه الزر.

```tsx
import Link from "next/link"

import { Button } from "@coss/ui/components/button"

export function LinkAsButton() {
  return <Button render={<Link href="/login" />}>تسجيل الدخول</Button>
}
```

## مرجع الواجهة البرمجية

مكوّن مخصّص يستخدم من مكتبة بيس `useRender` بدلًا من تغليف مكوّن جاهز مباشرة.

### الزر

مكوّن زر يدعم الأنماط والأحجام وحالة التحميل.

| الخاصية      | النوع                                                                                                              | الافتراضي     | الوصف                                                                 |
| --------- | ----------------------------------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------------------- |
| `variant` | `"default" \| "destructive" \| "destructive-outline" \| "ghost" \| "link" \| "outline" \| "secondary"`         | `"default"` | يحدّد نمط الزر.                                                 |
| `size`    | `"default" \| "icon" \| "icon-lg" \| "icon-sm" \| "icon-xl" \| "icon-xs" \| "lg" \| "sm" \| "xl" \| "xs"`     | `"default"` | يحدّد حجم الزر.                                                    |
| `loading` | `boolean`                                                                                                         | `false`     | يعرض مؤشر التحميل ويعطّل الزر أثناء التحميل.           |
| `render`  | `React.ReactElement`                                                                                              | -           | يعرض عنصرًا مختلفًا، مثل الرابط.                                  |

عندما `loading` هو `true`المكون:

- يعرض مؤشر تحميل (`data-slot="button-loading-indicator"`)
- يضيف `data-loading` إلى عنصر الزر الأساسي.
- يفرض الخاصية الأصلية `disabled` الخاصية
- يضبط `aria-disabled="true"`
- يحافظ على عرض الزر بإخفاء محتواه بصريًا بدلًا من إزالته.
