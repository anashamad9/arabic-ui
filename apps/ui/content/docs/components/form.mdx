## الاستيراد المحلي

بعد [استنساخ المستودع وتشغيله محليًا](/ui/docs/get-started)، استورد المكونات من الحزمة المشتركة داخل المشروع. لا تحتاج إلى سجل مكونات أو أمر تثبيت لكل مكوّن.

ملف المصدر: `packages/ui/src/components/form.tsx`. مسار الاستيراد: `@coss/ui/components/form`.

## الاستخدام

```tsx
import {
  Field,
  FieldError,
  FieldLabel,
} from "@coss/ui/components/field"
import { Form } from "@coss/ui/components/form"
import { Input } from "@coss/ui/components/input"
```

```tsx
<Form
  className="flex w-full flex-col gap-4"
  onSubmit={(e) => {
    /* handle submit */
  }}
>
  <Field>
    <FieldLabel>البريد الإلكتروني</FieldLabel>
    <Input name="email" type="email" required />
    <FieldError>يرجى إدخال بريد إلكتروني صحيح.</FieldError>
  </Field>
</Form>
```

## مرجع الواجهة البرمجية

### النموذج

غلاف رقيق حول واجهة المستخدم الأساسية `Form` بدون تخطيط افتراضي. تمرير **`className`** للتباعد والهيكل (على سبيل المثال `flex w-full flex-col gap-4` من أجل كومة حقل عمودي).

**الحوار ، ورقة ، درج:** مكان المكان **`DialogHeader`** (أو رأس ورقة / درج) **خارج** النموذج. التفاف **`DialogPanel`** و **`DialogFooter`** فقط في **`<Form className="contents">`** (أو **`<form className="contents">`**). **`contents`** قيمة العرض تحافظ على مشاركة اللوحة والتذييل بشكل صحيح في تخطيط الفليكس المنبثق دون تعشيش الرأس داخل `<form>`.
