**COSS UI/Arabic** تعريب لمكتبة coss UI بواسطة أنس حمد. الاستخدام المعتمد هو استنساخ هذا المستودع وتشغيله محليًا، ثم استيراد المكونات من ملفات الحزمة المشتركة.

## استنساخ المستودع

تحتاج إلى Git وBun بالإصدار `1.3.1` أو أحدث.

```bash
git clone https://github.com/anashamad9/arabic-ui.git
cd arabic-ui
bun install
bun run dev:local
```

افتح التوثيق والأمثلة على `http://localhost:4000/ui`. تحوّلك البوابة المحلية على `http://localhost:3001` إلى المكتبة نفسها.

## الاستيراد المحلي

المكونات في `packages/ui/src/components`، والخطافات في `packages/ui/src/hooks`، والأدوات المشتركة في `packages/ui/src/lib`. يربط Bun هذه الملفات عبر حزمة مساحة العمل المحلية `@coss/ui`؛ ليست حزمة منشورة تحتاج إلى تنزيلها منفصلة.

استخدم المكونات مباشرة داخل تطبيقات المستودع:

```tsx
"use client";

import { Button } from "@coss/ui/components/button";
import { Input } from "@coss/ui/components/input";

export function LocalExample() {
  return (
    <div className="flex items-center gap-2">
      <Input aria-label="الاسم" placeholder="اكتب اسمك" />
      <Button>حفظ</Button>
    </div>
  );
}
```

يمكنك تعديل صفحات `apps/ui/app` أو إنشاء صفحة جديدة فيها وتجربة المكونات. لا تحتاج إلى تثبيت كل مكوّن على حدة أو إلى خادم سجل مكونات؛ يعمل الاستيراد المحلي من الملفات حتى عندما تكون صفحة التوثيق مغلقة.

## الأنماط والخط

يستخدم التطبيق الأنماط المشتركة من الحزمة المحلية:

```css
@import "@coss/ui/globals.css";
```

خط ثمانية مضمن في المستودع ويُحمّل محليًا. إعدادات التطبيق والخط موجودة مسبقًا في `apps/ui/app/layout.tsx`.

```tsx
import { fontSans, fontMono } from "@coss/ui/fonts";
```

## الاتجاه العربي

تهيّئ تطبيقات المستودع `lang="ar"` و`dir="rtl"` ومزوّد الاتجاه مسبقًا. عند إضافة تخطيط جديد، استخدم مزوّد الثيم والاتجاه المشترك:

```tsx
import { ThemeProvider } from "@coss/ui/shared/theme-provider";

export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ar" dir="rtl">
      <body>
        <ThemeProvider>{children}</ThemeProvider>
      </body>
    </html>
  );
}
```

استخدم خصائص المسافات والمحاذاة المنطقية مثل `ms` و`me` و`ps` و`pe` و`text-start` عند تخصيص المكونات.

## استخدام الحزمة في تطبيق آخر

لإضافة تطبيق داخل مساحة العمل، أضف `"@coss/ui": "workspace:*"` إلى تبعياته وشغّل `bun install` من جذر المستودع. في تطبيق Next.js أضف `transpilePackages: ["@coss/ui"]` إلى إعداداته، واستورد الأنماط والخط ومزوّد الاتجاه كما هو موضح أعلاه. راجع إعدادات `apps/ui` كنموذج جاهز.

إذا نقلت الحزمة إلى مشروع آخر، انسخ مجلد `packages/ui` كاملًا مع ملفات الخط والتبعيات، وأدرجه ضمن مساحة العمل المحلية. احتفظ بملفات الترخيص ونسبة المصدر إلى coss UI.

## التحقق

```bash
bun run typecheck
```

لإنشاء نسخة محلية مبنية وتشغيلها:

```bash
bun run build
bun run start:local
```
