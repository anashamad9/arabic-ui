توفّر **COSS UI/Arabic** مكونات عربية جاهزة للنسخ والتخصيص. تعتمد على مكتبة بيس وتيلويند، وتراعي سهولة الوصول والتنقل بلوحة المفاتيح.

## المتطلبات الأساسية

ابدأ بمشروع رياكت يدعم تيلويند بالإصدار الرابع. شغّل هذه المكتبة محليًا ليكون سجل المكونات العربية متاحًا أثناء التثبيت.

## إضافة مكونات

يمكنك تثبيت المكونات عبر سطر الأوامر، أو نسخ شيفرتها يدويًا من تبويب **الكود**.

### مع سطر الأوامر

أضف السجل المحلي إلى ملف `components.json` في مشروعك:

```json
{
  "registries": {
    "@arabicui": "http://localhost:4000/ui/r/{name}.json"
  }
}
```

ادمج هذا الجزء مع الإعدادات الموجودة في الملف. ثم أضف مكوّنًا:

```bash
npx shadcn@latest add @arabicui/button
```

لإضافة جميع المكونات الأساسية:

```bash
npx shadcn@latest add @arabicui/ui
```

ولإضافة الألوان والأنماط المشتركة:

```bash
npx shadcn@latest add @arabicui/style
```

يستخدم هذا السجل ملفات النسخة العربية الموجودة في مشروعك المحلي. يجب أن يبقى خادم التوثيق على المنفذ `4000` قيد التشغيل أثناء التثبيت.

### يدويا

1. اختر المكوّن من [التوثيق](/ui/docs) أو [الأمثلة](/ui/particles).
2. افتح تبويب **الكود** وانسخ الملف إلى مشروعك.
3. ثبّت الحزم المدرجة في صفحة المكوّن.
4. عدّل مسارات الاستيراد لتطابق بنية مشروعك.
5. أضف المتغيرات والأنماط المشتركة الموضّحة في [دليل التنسيق](/ui/docs/styling).

## الاتجاه العربي

ضبط اتجاه المستند وحده لا يكفي لتحديد سلوك الأسهم والتنقل بلوحة المفاتيح. أضف مزوّد الاتجاه حول المكونات:

```tsx
"use client";

import { DirectionProvider } from "@base-ui/react/direction-provider";

export function ArabicProvider({ children }: { children: React.ReactNode }) {
  return <DirectionProvider direction="rtl">{children}</DirectionProvider>;
}
```

واضبط لغة المستند واتجاهه في التخطيط الرئيسي:

```tsx
<html lang="ar" dir="rtl">
  <body>
    <ArabicProvider>{children}</ArabicProvider>
  </body>
</html>
```

استخدم خصائص المسافات والمحاذاة المنطقية مثل `ms` و`me` و`ps` و`pe` و`text-start` عند تخصيص المكونات. اعزل الكود والأوامر عن اتجاه النص العربي:

```css
pre, code, kbd {
  direction: ltr;
  unicode-bidi: isolate;
}
```

## التصميم

تُعرّف الألوان والحدود وحالات التحميل والتفاعل بمتغيرات مشتركة. تستطيع تعديلها بما يناسب مشروعك. تشمل المتغيرات الإضافية ألوان المعلومات والنجاح والتحذير والأخطاء.

## الخطوط

تستخدم الواجهة **خط ثمانية** المحلي. انسخ ملفات الأوزان التي تحتاجها من `thmanyahsans/woff2` إلى مجلد `public/fonts` في مشروعك. تتوفر أيضًا [نسخة الخط العادي](/ui/fonts/thmanyahsans-Regular.woff2) و[الخط العريض](/ui/fonts/thmanyahsans-Bold.woff2) للتنزيل من خادم التوثيق المحلي.

```tsx
import localFont from "next/font/local";

const thmanyah = localFont({
  display: "swap",
  src: [
    { path: "../public/fonts/thmanyahsans-Regular.woff2", weight: "400" },
    { path: "../public/fonts/thmanyahsans-Bold.woff2", weight: "700" },
  ],
  variable: "--font-sans",
});
```

عدّل المسارات وفق مكان ملف التخطيط. ثم اربط المتغير بالجسم والعناوين:

```tsx
<body className={`${thmanyah.variable} font-sans`}>{children}</body>
```

```css
@theme inline {
  --font-sans: var(--font-sans);
  --font-heading: var(--font-sans);
}
```

توفّر الحزمة المشتركة داخل هذا المشروع الصادرات `fontSans` و`fontHeading` من `@coss/ui/fonts`. يحتاج المشروع المستقل إلى نسخ ملفات الخط كما هو موضّح أعلاه؛ إعدادات الخط في السجل تضبط أسماء العائلات ولا تنقل الملفات الثنائية تلقائيًا.

## الصادرات البدائية

تعيد المكونات تصدير عناصرها البدائية عند الحاجة إلى تخصيص أعمق. استخدم المكونات المنسّقة افتراضيًا، وانتقل إلى العناصر البدائية عند بناء تركيب خاص.

```tsx
import { Slider, SliderValue, SliderPrimitive } from "@coss/ui/components/slider";
```

## قاعدة واجهة المستخدم إعادة التصدير

في التطبيقات الموجودة داخل هذا المشروع يمكنك استيراد أدوات بيس من الحزمة المشتركة:

```tsx
import { DirectionProvider } from "@coss/ui/base-ui/direction-provider";
import { useRender } from "@coss/ui/base-ui/use-render";
```
