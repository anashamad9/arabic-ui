## نظرة عامة

تم تحسين مكتبة واجهة المستخدم هذه للعمل مع رموز ألوان محددة توفر حدودًا واضحة ومتناقضة وعمقًا بصريًا معززًا. يعتمد نظام التصميم لدينا على [نهج المتغيرات CSS في shadcn / ui](https://ui.shadcn.com/docs/theming) لضمان الاتساق والصيانة.

تستخدم مكوناتنا حدودًا مبهمة بدلاً من حدود صلبة لضمان حدود واضحة ومتناقضة حتى عندما تفتقر الخلفيات إلى التباين الكافي. تختلط هذه الحدود المعتمة مع الظلال السفلية لإنشاء تباين معزز وعمق بصري.

على الرغم من أن نظام الألوان هذا اختياري ، إلا أنه مصمم لتوفير نتائج بصرية مثالية. قد يؤدي استخدام رموز الألوان التقليدية إلى حدود وظلال غير متناسقة لا تحقق جودة التصميم المقصودة.

## متغيرات الخط

تستخدم الواجهة خط ثمانية للنصوص والعناوين، وخطًا أحادي المسافة للشيفرة. تُحمّل الملفات محليًا، ولا تعتمد على خدمة خطوط خارجية.

يحدّد `--font-sans` خط النص، ويستخدم `--font-heading` الخط نفسه. راجع [إعداد خط ثمانية](/ui/docs/get-started) لتنزيل الملفات وإضافتها إلى مشروع مستقل. أنماط السجل وحدها لا تنقل ملفات الخط.

داخل هذا المستودع، يمكنك استخدام التهيئة المشتركة:

```tsx title="app/layout.tsx"
import { fontMono, fontSans } from "@coss/ui/fonts";

export default function RootLayout({ children }) {
  return (
    <html lang="ar" dir="rtl">
      <body className={`${fontSans.variable} ${fontMono.variable} font-sans`}>
        {children}
      </body>
    </html>
  );
}
```

يحمّل `fontSans` الأوزان ٣٠٠ و٤٠٠ و٥٠٠ و٧٠٠ و٩٠٠. استخدم `font-medium` أو `font-bold` لتحديد الوزن المناسب للعناوين.

## إعداد واجهة المستخدم الأساسية

نظرًا لأن هذه المكتبة مبنية على واجهة المستخدم الأساسية ، فأنت بحاجة إلى تكوين عزل تنسيق لضمان عرض المكونات المدخلة (الحوارات ، Popovers ، Selects ، إلخ) بشكل صحيح فوق محتوى الصفحة.

### تطبيق عزل الجذر

إضافة `isolation: isolate` إلى مغلف الجذر للتطبيق الخاص بك. هذا يخلق سياق التراص منفصلة بحيث تظهر المكونات المدخلة دائما فوق محتويات الصفحة دون تعارضات z-index.

```tsx title="app/layout.tsx"
<body>
  <div className="isolate relative flex min-h-svh flex-col">
    {children}
  </div>
</body>
```

### توافق آي أو إس سفاري

لتوافق آي أو إس سفاري 26+ ، أضف `position: relative` إلى عنصر الجسم. هذا يضمن الخلفيات تغطية بشكل صحيح منفذ العرض المرئي بعد التمرير الصفحة.

```tsx title="app/layout.tsx"
<body className="relative">
  <div className="isolate relative flex min-h-svh flex-col">
    {children}
  </div>
</body>
```

تضمن هذه الأنماط أن تحافظ مكونات واجهة المستخدم الأساسية على التسلسل الهرمي للعرض والطبقات المرئية المناسبة في جميع أنحاء التطبيق الخاص بك. بدون عزلة ، قد تواجه تعارضات z-index حيث يظهر محتوى الصفحة فوق مربعات الحوار أو النوافذ المنبثقة.
