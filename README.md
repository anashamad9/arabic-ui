# COSS UI/Arabic

مكتبة واجهات عربية مفتوحة المصدر، مع أمثلة وتوثيق باللغة العربية، واتجاه من اليمين إلى اليسار، وخط ثمانية المحلي.

**COSS UI/Arabic تعريب وتكييف لمكتبة [coss UI](https://github.com/cosscom/coss)، أعدّه [أنس حمد](https://github.com/anashamad9).** يعود تطوير المكونات الأصلية إلى مشروع coss UI ومساهميه؛ تشمل مساهمة هذه النسخة تعريب الواجهات والتوثيق والأمثلة، وتهيئة اتجاه اليمين إلى اليسار، وإضافة خط ثمانية.

## التشغيل المحلي

يتطلب المشروع بيئة تشغيل `Bun` بالإصدار `1.3.1` أو أحدث.

```sh
git clone https://github.com/anashamad9/arabic-ui.git
cd arabic-ui
bun install
bun run dev:local
```

- مكتبة coss UI العربية: http://localhost:4000/ui
- بوابة محلية تحوّلك إلى المكتبة: http://localhost:3001

يشغّل الأمر الافتراضي مكتبة المكونات وبوابتها فقط. يحتوي المستودع الأصلي أيضًا على أمثلة إضافية، ومنها تطبيق المواعيد، لكنها ليست واجهة COSS UI/Arabic الرئيسية ولا تُشغَّل افتراضيًا.

لإيقاف الخوادم، اضغط `Ctrl+C` في الطرفية التي شغّلتها. إذا كان أحد المنافذ مشغولًا، أوقف النسخة السابقة أولًا.

لتشغيل النسخة المبنية محليًا:

```sh
bun run build
bun run start:local
```

## بنية المشروع

- `apps/www`: الموقع الرئيسي.
- `apps/ui`: المكونات الحديثة والأمثلة والتوثيق وملفات المصدر المحلية.
- `apps/origin`: المكونات السابقة بعد تعريب أمثلتها.
- `apps/examples/calcom`: تطبيق مواعيد تجريبي باللغة العربية.
- `packages/ui`: المكونات والخطوط المشتركة.
- `thmanyahsans`: ملفات خط ثمانية التي زوّد بها المشروع.

تبقى أسماء الدوال والمكتبات ومسارات الاستيراد والأوامر البرمجية ثابتة. تحمل النسخة العربية اسم `COSS UI/Arabic`، وتُستورد مكوناتها من الحزمة المحلية `@coss/ui`.

## استيراد المكونات محليًا

بعد استنساخ المستودع وتشغيل `bun install`، استخدم الحزمة المحلية داخل تطبيقات مساحة العمل:

```tsx
import { Button } from "@coss/ui/components/button";
import { Input } from "@coss/ui/components/input";
```

```css
@import "@coss/ui/globals.css";
```

المكونات في `packages/ui/src/components` والخطافات في `packages/ui/src/hooks`. الحزمة `@coss/ui` مرتبطة محليًا بمساحة العمل؛ لا تحتاج إلى أوامر تثبيت لكل مكوّن أو إلى موقع منشور. لإضافة تطبيق إلى مساحة العمل، أضف `"@coss/ui": "workspace:*"` إلى تبعياته ثم شغّل `bun install`. تحتوي صفحة البدء على تفاصيل الخط والاتجاه والإعدادات.

## اتجاه الواجهة والخط

تستخدم صفحات التطبيقات `lang="ar"` و`dir="rtl"`. يضبط مزوّد الاتجاه سلوك القوائم والتبويبات والمكونات التفاعلية، بينما تبقى الكود والأوامر والحقول التقنية معزولة باتجاهها الطبيعي. يُحمّل خط ثمانية محليًا بأوزان ٣٠٠ و٤٠٠ و٥٠٠ و٧٠٠ و٩٠٠.

راجع دليل البدء داخل التوثيق للتشغيل والاستيراد المحلي.

## التحقق

شغّل الخوادم المحلية قبل اختبارات المتصفح. تفحص الاختبارات اللغة والخط والتجاوب وسلوك المكونات على الحاسوب والهاتف.

```sh
bun run typecheck
bun run test:e2e
```
